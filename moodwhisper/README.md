# MoodWhisper

隐私优先的个人情绪记录与分析应用。

## 功能特性

- 🌡️ **快速记录** - 3秒完成一次情绪记录
- 🔒 **隐私优先** - 完全本地存储，数据只属于你
- 📊 **情绪趋势** - 可视化分析情绪变化模式
- 🌙 **深色模式** - 夜间使用更舒适
- 📤 **数据导出** - 支持 CSV 格式导出

## 技术栈

- Flutter + Riverpod + sqflite + fl_chart + go_router

## 开发

### 环境要求

- Flutter SDK 3.24+
- Dart 3.12+

### 安装依赖

```bash
flutter pub get
```

### 运行

```bash
flutter run
```
